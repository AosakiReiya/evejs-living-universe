# Changelog

## [v0.3.0] - 2026-07-31

Compatible with EVEJS v0.12.3.1.

Migration release. The PowerShell installer is replaced by a cross-platform Go
CLI (`xeve-patch`).

- New `xeve-patch` CLI with `install`, `verify`, `repair`, `uninstall`,
  `status`, `manifest`, `audit`, and `version` commands, plus an interactive
  menu when run without arguments.
- The monolithic `x-eve-living-universe.patch` is replaced by
  `patches/files/` (an overlay content tree) plus `patches/docker-overlay/`.
  The Go CLI copies overlay bytes exactly; it no longer depends on Git on the
  target host.
- New manifest v2 (`patches/manifest.json`) records the expected baseline and
  installed SHA-256/size for every touched file and is generated by
  `make manifest` / `xeve-patch manifest generate`.
- `xeve-patch verify --integrity` validates the release data itself.
- `xeve-patch repair` restores the exact installed state after local edits.
- New module index (`patches/modules.json`) assigns every overlay file to a
  subsystem; `xeve-patch modules` prints the module map and `audit` validates
  the index against the manifest.
- Manifest schema v3: every file entry carries its owning module, and
  `xeve-patch verify --module <name>` / `--tests` / `--filter` run the bundled
  `server/scripts/verify*.js` tests through isolated `node` processes.
- The module index and manifest generation are fully Go-based
  (`xeve-patch modules generate`); the toolchain has no Python dependency.
- Cross-platform builds (linux/darwin/windows x amd64/arm64) via the Makefile
  and GitHub Actions; release CI builds, packages, and publishes all platforms.
- v0.2.3 PowerShell scripts moved to `legacy/` for migration and fallback.
  Existing v0.2.3 installations must be uninstalled with the legacy scripts
  before installing v0.3.0.

## [v0.2.3] - 2026-07-31

Compatible with EVEJS v0.12.3.1.

- Install/verify/uninstall now track Docker overlay files in the install state
- Verify gains a `-PatchIntegrity` mode for pure patch-tree validation
- Uninstall restores overlay files correctly and leaves the baseline intact
- Restructure `.gitignore` to a standard blacklist style
- Audit excludes the local `tmp/` working directory
